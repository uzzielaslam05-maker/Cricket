🏏 Net Session

Shadow-batting at home with a real bat. An AI bowler delivers virtual balls; your phone senses your swing and scores your timing.

No sensor yet? Open Screen and press Space (or tap the pitch) to swing — good for testing. Pairing needs internet for the handshake; the page must be served over HTTPS.

How to use Net Session

Everything you need to set up and get the best out of the app.

1. Host the page (one-time)

The app must run over HTTPS so the phone can access motion sensors.

  1. Upload this index.html to GitHub Pages, Netlify, or any static host.
  2. Open the HTTPS link on both your computer and your phone.

2. Pair the Screen and the phone

  1. On the computer, open the link → choose Screen → open Settings (⚙) → Create pairing code.
  2. A 4-character code and a QR code appear.
  3. On the phone, either:
    • Scan the QR code (opens Bat sensor and fills the code automatically), or
    • Open the same link → Bat sensor → type the code → Connect.
  4. When both show “Connected ✓”, you are ready.
Network error? Make sure both devices are online. PeerJS needs a brief internet connection for the handshake. Try creating a new code if it fails.

3. Enable the sensor

Motion (recommended)

  • Strap the phone firmly to your forearm or the back of the bat handle.
  • Keep the screen on and rotation lock on.
  • Tap Enable motion and allow the permission.

Camera mode (for shot direction)

  • Stick bright tape (orange / green / pink) near the tip of the bat.
  • Place the phone on a stand at the bowler’s end, facing you.
  • Start the camera → tap the tape in the preview to lock its colour → swing.

4. Start a session

  1. On the Screen, open Settings and tap Start session.
  2. The AI bowler begins delivering. Swing when the ball arrives.
  3. Results appear on both the Screen and the phone.
No phone? On the Screen press Space to swing, or use arrow keys (← off side · → leg side · ↑ lofted · ↓ defensive) to test shot detection.

5. Phone live views (once connected)

After the sensor is connected you can open:

  • Live HUD — clean full-screen results, countdown and delivery info.
  • Pitch View — full pitch animation driven by the Screen (same ball you are facing).

Tips for better scoring

  • Use the Timing calibration slider if you are consistently early or late.
  • Increase Ball slow-down while learning; set closer to 1.0 for real speed.
  • Turn on Announce variation when you want to practise reading the ball.
  • Adaptive AI learns your weak variations and bowls more of them.

Troubleshooting

  • Motion not working → page must be HTTPS + permission granted.
  • Cannot pair → both devices need internet; try a new pairing code.
  • Swings not detected → raise sensitivity or strap the phone more tightly.
  • Camera not tracking → brighter tape, better lighting, re-tap the colour.
